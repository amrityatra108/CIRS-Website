## Recommended order

**001 → 002 → 003 → 005 → 004.**

001 first: it is the only one that changes how motion looks on every page of
the site, and it is the plan most worth seeing land on its own before anything
else moves. 002 next, because it touches the same file and the two together
are the founder page's whole performance story. 003 and 005 are independent
founder-page work. 004 last — it is the smallest diff but the most visible
single change, and it is easiest to judge on a page that is otherwise already
settled.

## Dependencies

None of the five depend on another to be correct. Two overlaps to know about:

- **001 and 002 both edit `assets/js/cirs.js`.** They touch different
  functions — 001 edits `show()` inside `startSweep()` and the `forEach` body
  in `failOpen()`; 002 adds a helper near the top of `boot()` and edits two
  `.filter()` callbacks, one of which is `startSweep()`'s. If 002 runs after
  001, `startSweep()` will already have been modified. Match on the quoted
  code, not on the line numbers.
- **003 and 005 both edit `assets/css/founder-journey.css`,** at lines 37/39
  and 61/64 respectively. No overlap, but line numbers shift if 003's rule is
  reformatted — again, match on content.

**Every line number in these plans is as of `a3a6ac2`.** Applying any plan
shifts the ones below it in the same file. Always locate the target by the
verbatim code quoted in the plan.

## Two things that apply to all five

- **Do not edit a root `.html` file.** Every `.html` at the repository root is
  generated by `tools/build-site.py` from `tools/partials/` and
  `tools/pages/<slug>.html`. Editing one by hand looks like it works and is
  silently undone by the next build, and CI fails on the drift. See CLAUDE.md.
- **`founder.html` already drifts on this branch.** Running
  `python3 tools/build-site.py` rewrites it (cache-buster `89-founder-15` →
  `94-founder-16`, and it drops a `<div class="progress" id="progress">`) for
  reasons that predate these plans. If you see that in `git diff` after
  building, it is not yours. Record the baseline with
  `git stash && python3 tools/build-site.py && git diff --stat -- '*.html'`
  before starting if you need to be certain.

## Checks before any push

From CLAUDE.md, in this order:

```sh
npx --yes html-validate@11 *.html      # structure and accessibility
python3 tools/check-links.py           # every link and asset reference resolves
python3 tools/build-site.py            # then: git diff --quiet -- '*.html'
```

`tools/check-contrast.py` is not needed for any of these five — none of them
touch a hero, a scrim or the honeycomb.

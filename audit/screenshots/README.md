# Why this folder is empty

Screenshots were captured and reviewed live during this audit (via the session's built-in
browser tool) and their findings are written directly into the relevant page sections of
[`../FULL_SITE_AUDIT.md`](../FULL_SITE_AUDIT.md) — search that file for
"screenshot-verified". The tool that captured them returns image data inline to the
auditing session; it does not provide a way to export those captures as saved `.png` files
in this environment, so there are no image files to place here. This is a tooling
limitation of the audit session, not a gap in what was reviewed — see "Methodology &
Coverage" at the top of `FULL_SITE_AUDIT.md` for exactly which pages/viewports were
screenshot-verified versus DOM/source-verified only.

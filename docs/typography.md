# Self-hosted typography

Newsreader is the default for all English text, including headings, body, navigation, controls, captions, data and articles. Literata is limited to `.crhero__lead` (the magazine introduction) and `.advert__sub` (the Admissions campaign introduction). EB Garamond italic carries block quotations, reflective statements, the motto transliteration, and selected heading emphasis. Tiro Devanagari Hindi carries Devanagari passages through semantic Hindi/Sanskrit language selectors.

The `.serif` class retained in existing templates is a legacy presentation hook. It now resolves to Newsreader; it is not a generic family declaration or fallback. Font synthesis is disabled, labels use restrained tracking, and no fallback family is intentionally configured. Small-cap simulation is removed because Newsreader does not contain small-cap glyphs.

## Font files and licensing

Eight local WOFF2 faces preserve the complete upstream character maps, OpenType shaping tables, true italics and variable axes. Newsreader covers weights 200–800, Literata 200–900, EB Garamond 400–800, and Tiro Devanagari Hindi uses its real 400 weight. Devanagari is never artificially bolded or slanted. Full character maps preserve Latin extensions/IAST, Devanagari shaping and available symbols; scripts are not reduced to the characters found in one content snapshot.

Each family uses SIL Open Font License 1.1. Full notices (with trailing whitespace normalized) are in `assets/fonts/licenses/` and are included in `_site/` by the staging script. Embedded copyright/license name records are preserved. `assets/fonts/manifest.json` records pinned source URLs, revision, checksums and output sizes. All eight files together total approximately 2.02 MiB; browsers fetch only faces actually used on the current page.

To reproduce the optional font assets, install `fonttools[woff]==4.62.1` in an isolated Python environment, then run `python tools/make-fonts.py`. This fetches pinned upstream files during asset preparation only. Visitors and the regular Python build have no external font-service dependency. `assets/css/fonts.css` is generated by this script, with stable approved family names and `font-display: swap`. The primary upright Newsreader face is preloaded to reduce the swap interval.

The font sources are pinned to Google Fonts repository revision `f2bd09badbc763d8757951d52deec29da27e85fb`; source authors and URLs are recorded in the manifest and license notices. WOFF2 conversion preserves glyph coverage and license metadata. Obsolete font files were removed only after reference replacement and a successful full build, staging, HTML validation and link check.

## Validation boundaries

Inspect rendered font families and actual browser font use as well as source declarations. Browser emergency glyph substitution is possible for glyphs absent from an approved face; it is not a configured fallback. Record these cases separately from missing glyphs. Font loading uses swap, so an uncached browser can briefly show internal emergency type before the local font arrives. Measure cold-load layout shift, and verify fixed/animated layouts after fonts settle.

Run the documented build, HTML validation and link check. Test all 42 desktop pages, the 17 main pages at tablet/mobile widths, and desktop at 200% browser zoom. Preserve keyboard focus behavior and the existing film iframe limitation from the accessibility repair.

## Genuine weight hierarchy

Embedded `fvar` axes, OS/2 weight/style flags and `post` italic angles were inspected for every WOFF2. The face declarations already match those files: Newsreader 200–800 (opsz 6–72), Literata 200–900 (opsz 7–72), EB Garamond 400–800, and static Tiro 400. Normal and italic are separate files; none uses an italic or slant axis. OS/2 weight 400 is the variable default, not a restriction to regular.

The shared final typography sheet assigns display/H1 600; H2/H3/H4 500 (existing sizes retain the levels); body and quotations 400; navigation/buttons 600; labels 500. Genuine EB Garamond italic emphasis stays at 400. Hindi/Sanskrit remains normal 400, including nested bold/heading markup. All selected weights exist; no unavailable-weight substitution is necessary. `font-synthesis:none` remains inherited throughout, with no variation override pinning the weight axis. The homepage hero is an explicit regular-400 exception requested after review. Asset revision 46 refreshes the changed stylesheet.

## Typography metric regressions

The homepage retains its original intentional break between the two phrases and genuine Newsreader 400. The animated line splitter groups words by overlapping vertical text bands, allowing Newsreader and EB Garamond to share a baseline without being mistaken for separate lines. This preserves the existing reveal animation and responsive resplitting.

Only three additional composition rules are needed: the Founder programme introduction has a 42rem maximum width to keep “The Chinmaya” together; the desktop static/swipe version of the first homepage day panel has a scoped panel width and responsive heading size; daily-routine headings balance their wrapping to avoid stranding “ready”. Mobile heading sizes, page copy, photographs and colours are unchanged by these corrections.
